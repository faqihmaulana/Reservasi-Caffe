# AURA Cafe — Reservasi Caffe

Website reservasi tempat/cafe dengan pengalaman memilih kursi secara visual.

## Fitur
- Landing page modern dengan visual 3D/isometric cafe.
- Pemilihan tanggal, jam, dan jumlah tamu.
- Floor plan interaktif dengan seat available, selected, dan occupied.
- Detail kursi dan reservation fee dinamis.
- Modal konfirmasi reservasi.
- Setelah dikonfirmasi, kursi berubah menjadi occupied pada sesi tersebut.
- Responsive untuk desktop dan mobile.
- Tanpa backend/database, cocok sebagai prototype frontend.

## Teknologi
HTML5 · CSS3 · JavaScript · Google Fonts
